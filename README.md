# CarHorizontal

CarHorizontal (CH) est un SaaS multitenant pour les garages automobiles : suivi des clients, des véhicules, de la maintenance, des rappels et de la communication. Monorepo composé d'une API ASP.NET Core (`apps/api`), d'un portail Next.js (`apps/portal`) et d'une stack d'infrastructure de déploiement (`infrastructure/`).

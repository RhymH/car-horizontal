## T7.1-E — Customer "+ Interaction" checklist

- [x] `AddInteractionDialog` POSTs `/api/customers/{id}/interactions` and
  invalidates `queryKeys.customers.detail(id)` on success — list refreshes
  immediately on add.
- [x] Type filter (Tous / Appel / Visite / SMS / Email / Note) wired in
  `CustomerInteractionsSection`.
- [x] Copy buttons on email and phone are wired via `navigator.clipboard`.

**Open follow-up (low severity)** — the BFF
`CustomerService.GetAsync` returns only the latest 5 interactions
(`.Take(5)`). The "Charger plus" button in `CustomerInteractionsSection`
slices the loaded array, so once a customer exceeds 5 interactions the
older ones are unreachable from the UI. To track for Phase 19 polish:
either remove the dead button or add a paginated
`GET /api/customers/{id}/interactions` endpoint.
